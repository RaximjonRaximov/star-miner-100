# Star Miner: 100 Missions

A simple but long-playable web idle/clicker game. Mine asteroids, sell resources, buy upgrades, and complete 100 missions.

## How to Play

1. Click the asteroid to mine resources.
2. Use the **Cargo Hold** panel to track resources and sell them.
3. Buy **Upgrades** to increase mining power, storage, drones, sell prices, rare ore chance, and unlock new asteroid belts.
4. Complete **Missions** to earn credit rewards.
5. Progress is saved automatically to your browser.

## Features

- 100 hand-generated missions with scaling difficulty
- 7 resource types across 7 asteroid belts
- 6 upgrade paths
- Procedural Canvas visuals (asteroid, ship, laser, particles, starfield)
- UI assets (banner and favicon) are generated for the interface; all in-game visuals are code-rendered
- Responsive layout for desktop and mobile

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript (no external game libraries)

## Run Locally

Open `index.html` in a web browser or serve the folder with a static server.
